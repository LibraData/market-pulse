指标口径与数据边界

S = 0.30 × 强度 + 0.25 × 广度 + 0.25 × 量能 + 0.20 × 位置。四项子分均限制在 −100 至 +100。

  • 强度：上证、深成、创业板、沪深 300 涨跌幅中位数 ×20；涨跌 5% 对应 ±100。四指数不齐时该项缺失。
  • 广度：[上涨家数 ÷（上涨家数 + 下跌家数）−0.5] ×200。使用沪深京 A 股明细，剔除零成交股票；平盘不进入分母。
  • 量能：今日沪深京 A 股成交额 ÷ 此前 20 个交易日成交额均值 ×50，正负方向取四指数涨跌幅中位数符号。成交额比值为 1 时，方向非零的子分为 ±50；方向为零时为 0。基准必须来自完整、连续的本地历史，不足时为缺失。
  • 位置：（上证收盘 ÷ MA20 −1）×100×5。MA20 包含当日与此前 19 个交易日；当前脚本还要求此前 20 个交易日记录齐全才启用，积累期间按约定为 0。
  • 缺失处理：缺失子分在 JSON 中为 null，不重新分配权重。页面显示部分维度合计并标记口径不完整；历史不足的位置 0 不代表真实均线距离为 0。
恐慌：S < −60偏冷：−60 ≤ S < −20中性：−20 ≤ S < 20偏暖：20 ≤ S ≤ 60过热：S > 60

相邻分档的端点按脚本确定：−60 属于偏冷，−20 属于中性，20 和 60 属于偏暖。

更新：GitHub Actions 计划于北京时间周一至周五 18:17 运行，平台可能延迟。脚本检查交易日，16:00 前、当日日线未更新、全零行情或核验不通过时跳过，不修改历史。同日重跑覆盖同日记录，写入前备份。

日期限制：使用带日期的上证日线交叉核验指数报价；新浪股票接口仅含时分秒，无法逐股确认报价日期。接口亦可能缺行、延迟或变更，指标仅用于观察。

连续记录：指截至最新记录连续覆盖的交易日数，不是 CI 执行次数；周末和交易所休市日不计入。
